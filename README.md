# 🧠 Intelligent RAG & Agentic AI System (LangChain + Gemini + FastAPI)

An end-to-end **Intelligent RAG (Retrieval-Augmented Generation)** and **Agentic AI** system that autonomously retrieves, reasons, and generates answers using **LangChain**, **Gemini LLM**, and **FastAPI**.  

This project blends **context-aware retrieval** with **autonomous agent workflows**, enabling multi-step reasoning, contextual Q&A, and real-time data augmentation.

---

## 🚀 Key Features

- 🧩 **Retrieval-Augmented Generation (RAG):** Combines vector-based retrieval and large language model (LLM) reasoning for factual, context-grounded responses.  
- 🧠 **Agentic AI Workflow:** Multiple intelligent agents perform retrieval, summarization, and evaluation autonomously.  
- ⚙️ **FastAPI Backend:** Modular, production-ready REST API for serving RAG queries and managing documents.  
- 🔗 **Gemini LLM Integration:** Uses Google Gemini for high-quality reasoning and factual answers.  
- 🧮 **Vector Store:** Uses FAISS for fast semantic search and context retrieval.  
- 📡 **Extensible Design:** Add new agents, data sources, or LLMs easily.
